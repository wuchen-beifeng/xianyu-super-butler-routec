## 5. 脱敏说明（本仓库副本 vs 线上真身）

本仓库是**脱敏后的开源副本**，与线上运行的真身在以下几处**故意不同**（功能等价）：

| 项 | 线上真身 | 本仓库 |
| --- | --- | --- |
| `global_config.yml` | 文件名不变，`COOKIES.value` 有真实 cookie | 改名 `global_config.example.yml`，`COOKIES.value: ""`；`Dockerfile.overlay` 的 COPY 已同步改名 |
| 内网 IP | 真实内网地址 | 占位符 `<VM102_IP>` / `<VM100_IP>` / `<VM101_IP>` / `<NAS_IP>` |
| 路线 C 令牌 | `slider_routec/token` 有真实值 | 文件不含（`.gitignore` 忽略），需自行生成 |
| `.env` | 有真实 `ADMIN_PASSWORD` / `SLIDER_ROUTE_C_TOKEN` | 只有 `.env.example`（占位符） |
| QQ 号 / 账号 ID | 真实值 | `<QQ_ID>` / 占位示例文本 |

部署时按 `README.md` §3.4 把占位符替换成自己的地址即可。
